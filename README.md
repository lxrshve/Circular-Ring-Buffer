# Circular-Ring-Buffer
## Описание
Полноценная реализация кольцевого буфера (Circular/Ring Buffer) на C++, совместимая со стандартами и STL

Контейнер спроектирован с упором на производительность и правильное управление ресурсами. Он поддерживает работу с пользовательскими аллокаторами (`std::allocator`), семантику перемещения (Move Semantics) и предоставляет собственные итераторы произвольного доступа (`Random Access Iterators`).

## Ключевые возможности 🚀
* **Два режима работы (Compile-time конфигурация):** 
Благодаря параметру шаблона `IsExtendable`, буфер может работать как классический кольцевой буфер фиксированного размера (перезапись старых данных при переполнении), так и как динамический контейнер (автоматическая реаллокация и увеличение `capacity` при нехватке места).
* **Собственные итераторы:** Написаны с нуля `Iterator` и `ReverseIterator`, удовлетворяющие требованиям `std::random_access_iterator_tag`. Корректно обрабатывают циклическое смещение `(head + pos) % capacity`.
* **Ручное управление памятью:** Разделение выделения сырой памяти и конструирования объектов. Использование `std::allocator`, `placement new` и явных вызовов деструкторов (`.~T()`).
* **STL Совместимость:** Контейнер можно использовать с `std::sort`, `std::find`, и другими стандартными алгоритмами.
* **Поддержка Rule of Five:** Корректно реализованы конструкторы/операторы копирования и перемещения.

## Сложность операций (Big O)
* `push_back` / `push_front` — **O(1)** (амортизированное O(1) при `IsExtendable = true`)
* `pop_back` / `pop_front` — **O(1)**
* Доступ по индексу `operator[]` — **O(1)**
